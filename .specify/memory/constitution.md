# Constitución · Portafolio de Maximiliano Marigno

Versión 1.0.0 · 2026-10-22

1. **Autonomía.** Ningún contenido principal depende de una API, una base de datos o una cuenta externa. Textos, imágenes, formación y CV se versionan en este repositorio. Los enlaces a proyectos son salidas opcionales.
2. **Fuente única.** `src/app/data/portfolio.json` es la fuente del contenido público y del contexto del asistente. `specs/001-portafolio-local/spec.md` es el contrato funcional. `docs/README.md` es el único índice documental.
3. **Veracidad.** No inventar experiencia, clientes, usuarios, resultados, pagos operativos, certificados o disponibilidad. Distinguir producto, sitio y propuesta visual. Los cursos de Platzi se incorporan cuando se entreguen sus certificados.
4. **Privacidad.** No publicar repositorios ni enlaces a ellos. No copiar secretos. Los certificados públicos deben ser versiones sin DNI u otros datos personales innecesarios. El CV actual se preserva hasta confirmar sus datos laborales.
5. **Experiencia.** Acceso por teclado, foco visible, contraste, diseño adaptable, movimiento reducido y ausencia de reproducción automática en el carrusel. La navegación y el contacto deben ser explícitos.
6. **IA en el proceso.** Por aclaración del usuario, se usa IA para diseño y desarrollo. No añadir chatbot ni modelos a la experiencia pública.
7. **SDD.** Cambiar especificación antes de ampliar comportamiento; mantener trazabilidad entre requisitos, implementación y evidencia. Los pendientes externos se registran como pendientes, nunca como completos.
